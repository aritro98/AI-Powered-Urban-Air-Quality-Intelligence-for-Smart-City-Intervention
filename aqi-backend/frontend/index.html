Built for ET AI Hackathon 2.0 — Round 2 Build Sprint. Backend: FastAPI + 5 real public APIs (Open-Meteo weather & CAMS-backed air quality, OSM Overpass land-use, NASA FIRMS satellite thermal anomalies, TomTom live traffic, OpenAQ ground stations) with a 6-agent multi-agent architecture (Data / Attribution / Forecast / Enforcement / Advisory / Validation, coordinated by an Orchestrator). Includes real wind-direction causal reasoning, a Holt-Winters forecasting model backtested against persistence, and a circuit breaker for graceful degradation when an external API is down. Every agent has an LLM reasoning hook (reason_with_llm) that activates automatically once ANTHROPIC_API_KEY is set — currently running in heuristic/statistical mode.
